THE DEWEES INVITATIONAL — PRODUCTION WEBSITE STARTER

This is a complete, responsive, animated website designed for free hosting on GitHub Pages.

WHAT IS INCLUDED
- Animated full-screen hero with rotating photography
- Current-event information modal
- Evolving-event story section
- Interactive year-by-year timeline
- Year archive modal
- Hall of Champions section
- Traditions section
- Filterable photo gallery
- Full-screen photo lightbox
- Responsive mobile navigation
- Scroll animations
- SEO and social sharing metadata
- GitHub Pages custom-domain CNAME file

IMPORTANT LOGO NOTE
The file assets/logo.png is the currently available no-date logo. Replace that one file later with the official current logo, retaining the filename logo.png. The entire site will update automatically.

HOW CONTENT IS UPDATED
- Event date/location: data.js
- Timeline years and records: data.js
- Text and major sections: index.html
- Photos: assets folder

HOW TO PUT IT LIVE
1. Create a free GitHub account.
2. Create a public repository named dewees-invitational.
3. Upload the CONTENTS of this folder to the repository root.
4. In Repository Settings > Pages, publish from the main branch and root folder.
5. In Pages > Custom domain, enter deweesinvitational.com.
6. Add GitHub's required DNS records in Porkbun.
7. Turn on Enforce HTTPS after the domain is verified.

The CNAME file is already included for deweesinvitational.com.
