HOW TO UPDATE GITHUB
1. Open the DIwebsite repository.
2. Click Add file > Upload files.
3. Open this unzipped folder on your computer.
4. Select everything inside it, including the assets folder.
5. Drag the selected contents into GitHub.
6. GitHub will show existing files as changed/replaced.
7. Enter a commit message such as: Full champions and timeline update
8. Click Commit changes.
9. Wait about 1–3 minutes, then refresh the live website.

Do not upload the ZIP itself. Upload the unzipped contents.
